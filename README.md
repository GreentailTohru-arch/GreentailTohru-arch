## 关于我 / About me

我是 **Ren Kobayashi**，在 **Ren Design Studio** 探索设计、代码与交互的结合。

在这里，我把想法做成可以使用的软件和可以体验的作品：从专注工具，到网页交互，再到视觉实验。希望每一个作品都兼顾清晰的功能与细腻的体验。

### Tomatotodo — 让每一份专注，随你同行

面向 **Windows、Android 手机与平板** 的专注与任务管理软件。

- **专注与计划**：番茄计时、短休、正向计时，以及任务清单。
- **自己的工作台**：可调整的仪表盘组件、日夜外观与主题色。
- **看见积累**：专注日历、每日记录、统计图与热力图。
- **跨设备体验**：课程表、云端同步，以及 JSON 数据导入与导出。

[访问官网](https://greentailtohru-arch.github.io/Tomatotodo/) · [查看源码与使用说明](https://github.com/GreentailTohru-arch/Tomatotodo) · [下载安装包](https://github.com/GreentailTohru-arch/Tomatotodo/releases)
